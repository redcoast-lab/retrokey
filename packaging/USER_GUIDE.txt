retrokey

1. Windows は retrokey.exe、macOS は retrokey.app を開いてください。
2. 入力したい言葉を入れ、「変換」を押してください。Enter でも変換できます。
3. 表示された「押すキー」をゲームで順に押してください。
4. 「コピー」でキー列だけをコピーできます。

画面下の左側は直近20件の変換履歴、右側はピン止めです。
履歴は新しい順に表示し、20件を超えると古いものから消えます。
履歴を選ぶと入力と結果を呼び出せます。「ピン止め」で右側に残せます。
ピン止めは履歴から消えても残ります。「ピン止めを解除」で削除できます。
履歴とピン止めはアプリを閉じても端末内に保存されます。

全角カナ・半角カナ・ひらがなのどれでも入力できます。
Shift+3 は Shift を押しながら 3 を押す操作です。
¥ は上段の円記号キー、＼ は右 Shift の左のキーです。
現代の日本語 JIS キーボードを前提にしています。
ゲーム側のカナ入力を有効にしてから使ってください。

実機配列として正しくても、エミュレータ設定によってキーが異なる場合があります。
Project EGG 上での文字入力は未検証です。

Python のインストールと管理者権限は不要です。
Windows の Defender / SmartScreen、macOS の Gatekeeper が警告する場合があります。
Developer ID 署名・notarization・Windows コード署名には未対応です。
